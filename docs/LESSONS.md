# Lessons

What Claude learned working on this repo: mistakes (and what to do instead), missed opportunities, and ideas. The learn mod
(`.claude/skills/learn`) asks for a lesson when a turn had a correction, a failed check, a guard stop or a release, and shows
each lesson again when the code it's about is touched. Written with `node tools/learn.mjs` (see its header); hand edits are
fine if the line format stays. Public repo: no game titles, scores or personal data here.

## Mistakes

- **L1** ×2 · 2026-10-11 · v267 · `bugLayoutSoon`, `tools/kit.mjs` — A sweep that moves to the next screen 1.5s after switching misses the layout check (it runs 1.6s after a screen change, when idle): wait 2.6s per screen; a planted cut-off button went from 1 to 11 screens reported
- **L2** · 2026-10-11 · v267 · `.claude/skills/release-guard`, `claude plugin test` — release-guard's merge test had been failing unnoticed since a Claude Code update changed what test hooks on session.append must return (call next): after a Claude Code update, run claude plugin test on every mod in .claude/skills, not only the one being changed
- **L4** · 2026-10-12 · v269 · `tools/kit.mjs`, `--file` — kit.mjs --file resolves the path against the repo root, so a scratchpad path fails with ENOENT: write the old copy as old.html in the repo root (git show origin/main:index.html > old.html), run, then rm it (never commit it)
- **L5** · 2026-10-12 · v269 · `tools/where.mjs`, `acorn` — A fresh container has no acorn, so tools/where.mjs throws 'acorn not found': run npm i -g acorn first
- **L6** · 2026-10-12 · v269 · `issue comments`, `bugPath` — Wrote an issue comment guessing what an element id was (#dxq called a queue tile; it was the search box, which explained the whole report): grep the id in index.html before describing or diagnosing a report
- **L7** · 2026-10-13 · v272 · `worker/helper.js`, `ask`, `fake env` — Wrote a helper fix (#428, half an emoji from .slice) and a fake AI to prove it, but JSON.stringify escapes lone surrogates as valid JSON, so the fake passed before and after: a fake that only encodes my own guess proves nothing; when the live service can't be reached, comment the hypothesis and leave the issue open instead of shipping
- **L8** · 2026-10-13 · v273 · `.claude/skills/*/hooks/*.tsx`, `claude plugin test` — In a .tsx mod I named a loop variable h (a Helper), which shadows the JSX factory h, so every element inside threw 'h is not a function' and the render hook was skipped → never use h as a variable name in a .tsx hooks module (use x or a real name).
- **L9** · 2026-10-13 · v274 · `.claude/settings.json`, `enabledPlugins`, `mods/`, `claude plugin list` — I told the owner Play next would switch the shared mods on through .claude/settings.json enabledPlugins without testing it in a cloud session; the next chat had nothing installed → check a new loading path in a fresh session (claude plugin list / installed_plugins.json) before saying it works; in this repo, mods load from .claude/skills (symlinks to mods/ count).
- **L10** · 2026-10-13 · v277 · `tools/audit.mjs`, `--fix-css`, `kit.mjs samecss` — A CSS text tool cut through url(data:…;…) values and took a rule's closing } with its last declaration (no trailing ;): 2,900 rules changed. Parse on a masked copy (strings, (…) and comments blanked to the same length), never cut past a rule's }, and prove every CSS tidy with node tools/kit.mjs samecss --before old.html (the browser's own winning declarations)
- **L11** · 2026-10-13 · v277 · `auto-bug`, `bugsync`, `issue body` — An auto-bug issue's Versions / Times / First-last table is the FIRST report only; later sightings are bugsync comments ('Seen N more … Latest: vN'). Read the comments for the latest version before calling a report stale or closing it
- **L12** · 2026-10-13 · v277 · `hubDragStart`, `touchmove`, `touch-action`, `#full .hub` — Chrome latches a touch scroll on the first move, even a sideways one: later vertical moves scroll the page and preventDefault on touchmove is ignored (cancelable=false). Lock a swipe's axis with touch-action on the scroller (pan-y pinch-zoom) plus a JS axis pick in the first 10px; test with CDP touch at 859 too (412 passed while 859 failed)
- **L13** · 2026-10-13 · v279 · `tools/lint.mjs`, `expected`, `function declaration` — Two function declarations with one name in one script: the later one silently wins everywhere, and callers written for the earlier one get the wrong shape (undefined fields, features that never show). The lint's no-redeclare catches it; when it fires, rename one (expectedInfo) and check every caller's use of the result
- **L14** · 2026-10-13 · v279 · `.github/workflows`, `app-check.yml`, `YAML` — A step name with ': ' in it broke app-check.yml (GitHub shows the run under the file path and fails it at once, so the PR check silently never ran). Quote names with colons, and validate every workflow before pushing: python3 -c "import yaml;yaml.safe_load(open(f))"
- **L15** · 2026-10-14 · v280 · `mods/heads-up`, `mods/crew`, `$.ui.open`, `docs/LOG.md` — A mod panel didn't show in the desktop app and I chased a 144-column width limit through two releases, while docs/LOG.md already said cloud chats draw no mod UI at all (only Local chats on the PC do) → before debugging a mod's panel/band/toast, grep docs/LOG.md for 'cloud chat' / the mod's name, and design anything the owner must see in a cloud chat as text in the reply.
- **L16** · 2026-10-14 · v280 · `tools/kit.mjs`, `smooth`, `pnEvo`, `nxEvo` — A test that turns off a timed feature after the page loads is too late when the app schedules it at load (Nexi's 15s power-up): put the setting in the seed passed to phone() so it is there before the load.
- **L17** · 2026-10-14 · v280 · `tools/*.mjs`, `import.meta.url`, `.gitattributes` — Tools must work on the owner's Windows PC too: find files with fileURLToPath(import.meta.url), import with pathToFileURL(p).href, split lines on /\r?\n/; never new URL(import.meta.url).pathname or a bare absolute path.
- **L18** · 2026-10-14 · v280 · `gh pr merge`, `set_auto_merge` — GitHub auto-merge is turned off in this repo (set_auto_merge fails): once node tools/kit.mjs all has passed on the branch with main merged in, merge with gh pr merge N --squash --delete-branch instead.
- **L19** · 2026-10-14 · v280 · `gh pr create`, `PowerShell` — On the Windows PC, PowerShell 5.1 splits a --body with double quotes inside into stray arguments (gh: unknown arguments): write PR text to a scratchpad file and pass --body-file, and use the Bash tool for claude -p (PowerShell passes no prompt).
- **L20** · 2026-10-14 · v280 · `Bash`, `node`, `python` — On the Windows PC the Bash tool has no node on PATH and there is no python: run node as /c/Program Files/nodejs/node.exe (or use PowerShell after refreshing PATH), and write multi-line edit scripts to a scratchpad .cjs file.
- **L21** · 2026-10-14 · v280 · `mods/*/hooks`, `register.tsx` — A mod module that declares a variable named on (the register arg) fails to load (on is declared again): never name a local on, even inside a render callback; run claude plugin test right after each mod edit.
- **L22** · 2026-10-14 · v280 · `.claude/skills/learn`, `turn.complete`, `M8` — The learn mod's 'asked for something automatic' trigger fired on a handoff brief (the first message came from another session, not the person) → treat a session-sent first message like a system-reminder: scan only words the person typed (fold into M8).

- **L24** · 2026-10-14 · v280 · `mods/heads-up`, `mods/crew`, `panel design` — heads-up 0.7 added chips, hover whys, ⓘ taps, an Earlier list and Done folds on top of the picked design; the owner's first look was 'whoaah too much' and asked to strip it → for anything the owner glances at (panels, bands, popups), ship the fewest parts that do the job, keep nothing between messages unless asked, and offer extras as options instead of building them
