## 2. The opening reel (`#pnboot`)

**Flow.** Black full-screen layer on top of everything from the first paint (z 10000, `touch-action: none`). It paints frame t=0 at once: a 44-unit blue square (`--B 77,163,255`), the "glowing pixel". Waiting state (v291): a 200 px radial glow behind the pixel (`rgba(--vrgb)` .6 → .2 at 45% → 0; animation 2.4 s ease-in-out infinite, opacity .45↔1, scale .82↔1.08), "Tap to play" (Poppins 600 15px, `--ice`, 70 px under centre, fades in over .5s after .3s), "Skip" button at the foot (min-height 44, 13px 600 `--mute`, bottom 18px + safe area). **Why a tap:** the browser needs one to allow sound; Android doesn't, but the Brief keeps the tap ("a tap plays the 15-second reel"). Sound plays only if `S.sound` (Sounds) is on; with it off the reel is silent but plays.

Android's calm = `LocalCalm` (the web's `html.still`/reduced motion); the reel is not shown with calm.

**Motion.** One copy of the strip (all tiles + 10 padding) is repeated enough times to cover the rail height plus one (`n = max(2, ceil(view/copy)+1)`); one Web Animation moves the stack up by exactly one copy's height, `linear`, infinite, **15 px per second** (`RLV_SPEED`; `duration = copyHeight / 15 s`), so it loops with no seam; only `transform` moves. If everything fits (`n < 2`, nothing to scroll) it doesn't move. The duplicates are `aria-hidden`, no tabstop.
**Touch.** Finger down: the drift pauses (`hold = -1`). Drag (> 8 px): scrubs, `currentTime = start − dy/15 s` wrapped, both directions, no inertia; a drag never counts as a tap. **Update triggers.** (1) a new copy of the backup arrives (`Games` state → Ready with a new `copyAt`) → `updateAll()`; (2) midnight local (a `WorkManager` one-shot re-armed every day, work-runtime is a dependency; "Out in N days" ticks over at 00:00 on the phone's zone, the web uses the UAE one only for its own docs: use the phone's zone like `Queue`/`Times` do), plus a boot/`ACTION_DATE_CHANGED`/`TIMEZONE_CHANGED` receiver (Receivers.kt has two receivers, add one); (3) release day (the same midnight job; the Countdown widget goes to "Out today"/"Out now" and Nexi's line to the party colours); (4) the app saving a change on this phone. No periodic polling (battery), no network.
**House rules:** black theme and the game's colour only; drawn icons, never emoji; no animation (widgets can't, and the web's "no press animation" holds); read-only (nothing changes a game until switch day; the Phase 10 widgets "Played it"/start a session are later).
