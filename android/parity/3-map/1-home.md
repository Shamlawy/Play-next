## 1. What `renderHome` computes first (shared by every tile)

- `live` = games not played and not dropped. `deck = onDeckScores()` (a game with no score, i.e. competitive, = -1). **`ranked` = live sorted by deck score desc, then `elo` desc (default 1500), then hype desc.** `pick = ranked[0]`, `runner = ranked[1]`, `settled` = duels with a winner, `dated` = live with a date, sorted by date. `hours` = sum of `hrsOf` of live (competitive = 0). `ev` = `S.evening` clamped 1..12, **default 4** (Android `Queue.evening` defaults 2.0: see section 9).
- `off` = `new Set(S.homeHide)`; **`sessions` is added when `S.timerOn` is false** (the timer is an extra). `on(k)` = not in `off`. `tint = S.homeTint !== false` (Standings rows only). `cnt = S.homeCount !== false` (the "(N)" counts in the tabs and "Next out (N)" is NOT behind it: always shown).
- Everything is redrawn from scratch (`el.innerHTML`) on any change; Android: plain recomposition from `Queue` + `Rank`, no DOM patching.
- Entrance (only the first open per app run): `html.first` pieces `pnRise` (opacity 0 + translateY 18px + scale .98 -> none) .6 s `--ease`, stagger 0 / .05 / .1 / .15 / .2 s for children 1,2,3,4,5+; off with calm/Still. Count-up (900 ms, ease-out cubic `1-(1-k)^3`) rolls the `.tile .big` numbers inside the stacks only (NOT the queue count, not the donut); skipped in calm. Low value: do it for the visible stack card only, or leave it out.

## 7. Hold to edit and where it is kept

- `pnHold` (11961): a `pointerdown` on a stack starts a 550 ms timer; a move over 10 px, up, cancel or leave stops it; at 550 ms: a 18 ms buzz and `pnStackEdit(key)`; the click that follows is swallowed. Nothing else changes while holding (no press look). Touch menu (`contextmenu`) is cancelled.
- Sheet `#stkedit` (11970): scrim; panel "Edit this stack" / "Order and pick which cards it holds."; one row per card of that stack (name = the card's title text *now*, so the year/month names and the swing card's game title change): name, ↑, ↓ (disabled at the ends), **Shown / Hidden** toggle (a hidden row dims). Reset (ghost): deletes `S.stackCfg[key]`, redraws and closes at once. Done: writes `S.stackCfg[key] = { order: [ids...], hidden: [ids...] }`, redraws, closes (`out` class, 220 ms). A tap on the scrim closes without saving. An all-hidden stack shows "Everything here is hidden. Hold to edit." and can still be held. Cards new since you last ordered sort **first** (index -1). Order is by id, so a card whose data is gone just isn't shown (it isn't kept in a stack's list either: `pnStackAll` is rebuilt every draw).
- Keys: `S.stackCfg.sB` and `.sC` (`{order, hidden}`), `S.homeHide` (array of switch keys), `S.standN`, `S.homeTint`, `S.homeCount`, `S.dzX.play`, `S.tonightH`, `S.hintLast`, `S.nxHomeOff`, `S.analysisAt`, `S.timerOn`, `S.evening`, `S.userName`, `S.reelOff` (piece 5). In memory only (practice copy) until switch day; the stack position is not kept.
- Sound: `beep("open")` on every tile tap that changes screens (`goTab`, month bar, ticket), `beep("tap")` on the tonight chips; Android: its Sounds switch (`Sounds.play`). Nothing else on Home makes a sound except the reveal (piece 4).
